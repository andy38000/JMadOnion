## 功能概述

Animation Library 是一个功能强大的 Maya 动画管理工具，可以帮助动画师：

- ✅ 保存和加载动画/姿势到本地库
- ✅ 动画缩略图预览（鼠标悬停自动播放）
- ✅ 命名空间映射（跨角色应用动画）
- ✅ 动画镜像（左右翻转）
- ✅ 时间缩放（调整动画速度）
- ✅ 收藏夹和最近使用
- ✅ 标签分类和搜索
- ✅ 姿势权重混合

## 安装方法

### 方法一：直接运行

将以下代码复制到 Maya 脚本编辑器（Python）中运行：

```python
import sys
sys.path.append(r"你的路径/scripts/maya/JpyModules")
import animation_library
animation_library.run()
```

### 方法二：添加到工具架

1. 将 `animation_library.py` 放入 Maya 脚本路径
2. 在 Maya 中创建工具架按钮，命令为：

```python
import animation_library
animation_library.run()
```

## 快速开始

### 保存第一个动画

1. 在场景中选择角色控制器
2. 设置帧范围（开始帧和结束帧）
3. 输入角色名称（如 "Character_A"）
4. 输入动画名称（如 "Walk_Cycle"）
5. 点击 **"Add to Library"**

### 加载动画

1. 在动画库中找到需要的动画
2. **左键点击** 打开预览窗口
3. 点击 **"Load Animation"**
4. 设置命名空间映射（如果需要）
5. 确认加载

## 功能详解

### 保存动画

#### 保存完整动画

1. **选择控制器**：在场景中选择所有需要保存动画的控制器
2. **设置帧范围**：
   - Start Frame: 动画开始帧
   - End Frame: 动画结束帧
3. **选择模式**：确保选中 "Animation"
4. **命名**：
   - Character Name: 角色/分类名称
   - Animation Name: 动画名称
5. **保存**：点击 "Add to Library"

#### 保存单帧姿势

1. 选择控制器
2. 选择 **"Single Pose"** 模式
3. 当前帧将被保存为姿势
4. 输入名称并保存

> 💡 **提示**：姿势会在缩略图右上角显示 "POSE" 标记

---

### 加载动画

#### 基本加载流程

1. **预览动画**：鼠标悬停在缩略图上查看动画预览
2. **打开加载对话框**：左键点击缩略图
3. **配置加载选项**：

| 选项 | 说明 |
|------|------|
| **Namespace Mapping** | 将源动画的命名空间映射到目标角色 |
| **Mirror Options** | 启用镜像并设置前缀/后缀 |
| **Time Scale** | 调整动画播放速度 |
| **Load Mode** | 选择加载模式（替换/插入/混合） |

#### 加载模式

| 模式 | 说明 |
|------|------|
| **Replace** | 替换当前帧的关键帧 |
| **Insert** | 添加到现有动画上（不删除原有关键帧） |
| **Blend** | 与现有动画混合（需要设置混合权重） |

### 镜像功能

镜像功能可以将动画从角色的一侧翻转到另一侧。

#### 设置镜像规则

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| Left Prefix | `L_` | 左侧控制器前缀 |
| Right Prefix | `R_` | 右侧控制器前缀 |
| Left Suffix | `_L` | 左侧控制器后缀 |
| Right Suffix | `_R` | 右侧控制器后缀 |

#### 镜像值

勾选 **"Mirror Values"** 后，以下属性会自动取反：
- TranslateX (TX)
- RotateY (RY)
- RotateZ (RZ)

#### 使用示例

原始动画在 `L_arm_ctrl` 上：
- 启用镜像后，动画会应用到 `R_arm_ctrl`
- TranslateX 值会取反（如 10 变为 -10）

---

### 时间缩放

时间缩放功能可以改变动画的播放速度。

| 缩放值 | 效果 |
|--------|------|
| **0.5x** | 慢动作（动画时长翻倍） |
| **1.0x** | 正常速度 |
| **2.0x** | 快进（动画时长减半） |

#### 计算公式

```
新帧位置 = 当前帧 + (原始帧 - 起始帧) / 缩放值
```

### 收藏夹

#### 添加到收藏夹

1. **右键点击** 动画缩略图
2. 选择 **"☆ Add to Favorites"**
3. 动画会显示金色星标 ⭐

#### 查看收藏夹

- 收藏的动画会出现在 **"⭐ Favorites"** 标签页中

#### 移除收藏

1. 右键点击已收藏的动画
2. 选择 **"★ Remove from Favorites"**

---

### 标签和备注

标签功能帮助您更好地组织和搜索动画。

#### 添加标签

1. **右键点击** 动画缩略图
2. 选择 **"Edit Tags & Notes..."**
3. 在标签输入框中输入标签（逗号分隔）
4. 或点击快捷标签按钮快速添加
5. 点击 **"Save"**

#### 建议标签

| 类型 | 标签示例 |
|------|----------|
| 动作类型 | walk, run, idle, jump |
| 战斗动作 | attack, hit, death |
| 属性 | loop, additive |
| 部位 | facial, body, hand |

#### 搜索标签

在搜索框中输入标签名称，会自动过滤显示匹配的动画。

---

### 姿势权重混合

加载姿势时可以使用权重滑块进行混合：

#### 控制选项

| 选项 | 说明 |
|------|------|
| **Pose Weight** | 姿势混合权重 (0-200%) |
| **Allow Negative** | 允许负权重 (-100% ~ 200%) |
| **Selection Only** | 仅作用于当前选择的控制器 |
| **Live Preview** | 实时预览效果 |

#### 属性过滤

| 筛选 | 说明 |
|------|------|
| **T** | Translate 位移属性 |
| **R** | Rotate 旋转属性 |
| **S** | Scale 缩放属性 |
| **OTHER** | 其他自定义属性 |

## 常见问题

### Q: 动画加载后位置不对？

**A**: 检查命名空间映射是否正确。确保源动画的控制器能正确映射到目标角色。

### Q: 中文文件夹名显示乱码？

**A**: 工具已支持中文路径，如果仍有问题，尝试将库路径改为纯英文路径。

### Q: 如何批量应用动画到多个角色？

**A**: 目前需要分别加载，后续版本会添加批量功能。

### Q: 保存的动画文件在哪里？

**A**: 默认路径：`~/Documents/maya/animations/`  
可以通过 **"Change Library Path"** 修改。

### Q: 如何备份动画库？

**A**: 直接复制动画库文件夹即可。每个动画包含：
- `animation_data.json` - 动画数据
- `{name}_preview/` - 预览图片文件夹

### Q: 支持哪些 Maya 版本？

**A**: 
- Maya 2016-2019 (Python 2.7 + PySide)
- Maya 2017-2021 (Python 2.7 + PySide2)
- Maya 2022+ (Python 3 + PySide2)
